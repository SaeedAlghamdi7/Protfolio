# Saeed Alghamdi — Graphic Design Portfolio

A responsive bilingual (Arabic/English) static portfolio website with six pages:
- Home (`index.html`)
- Work (`work.html`)
- Services (`services.html`)
- About (`about.html`)
- Process (`process.html`)
- Contact (`contact.html`)

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, run a local static server (for example VS Code Live Server).

## Before publishing — important personalisation
- Replace the concept projects in `work.html` with your real portfolio images and project descriptions. The current poster visuals are illustrative placeholders, not client work.
- In `contact.html`, replace the placeholder email and Instagram details with your real contact links.
- In `app.js`, replace `hello@saeedalghamdi.design` with your actual email address so the contact form opens a message addressed to you.
- Update the page descriptions and service details if needed.

## Design system
- Burgundy: `#A80F32`
- Ink: `#101012`

- Sand: `#C9B9AA`
- Arabic type: IBM Plex Sans Arabic
- Latin type: Inter
